# nevcan.com v7 (2022–2026)

The seventh version of nevcan.com, online from August 2022: my site as a GUE instructor and diving
educator, with courses, a class calendar, gear rental prices and underwater projects.

It is the site at **[nevcan.com](https://nevcan.com)** until v8 takes over www.nevcan.com. It then
moves to v7.nevcan.com as part of the nevcan.com version archive, hidden from search engines.

## Pages

| Path | Page |
| --- | --- |
| `/` | Home: about, professions and organizations, personal bests, conservation and exploration projects, courses and coaching, GUE communities |
| `/courses/` | GUE courses |
| `/calendar.html`, `/calendar/` | Class calendar |
| `/rental.html` | Equipment rental prices |
| `/guetv/` | GUE.tv discount |
| `/map/` | Countries I have visited |
| `/amphoraai/` | Amphora AI project page |
| `/gue/`, `/agisoft/` | Shared documents |

## Stack

HTML, CSS and jQuery on the Foundation framework, with Slick, Masonry and jQuery Validate; Font
Awesome and Fontello icons. Hosted on GitHub Pages.
